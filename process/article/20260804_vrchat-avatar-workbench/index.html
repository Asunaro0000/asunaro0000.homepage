VRChat Avatar Workbench

VRChatアバター制作時に使うPhysBone、マスク、マテリアル、アニメーション確認を、共通のAvatar Rootから扱うためのUnity Editor拡張です。各機能は個別Editorとして開き、このページから操作マニュアルへ移動できます。

マニュアル構成

VRChat Avatar Workbench ├─ PhysBone Editor ├─ Mask Editor ├─ Animation Preview ├─ Material Viewer └─ PhysBone Preset Library
PhysBone EditorPhysBone・Colliderの一覧管理、値の編集、コピー、プリセット、バックアップ。 Mask Editorマスクスロットの確認、UVオーバーレイ、ブラシ編集、保存・プリセット管理。 Animation PreviewAnimation Clipの再生確認、速度・時間操作、初期ポーズへのリセット。 Material ViewerRenderer / Material / Textureの確認と差し替え、lilToon設定の確認。 PhysBone Preset LibraryCSV候補の検索・比較・動作確認・採否判定とライブラリ登録。

共通の使い方

  1. Tools → VRChat Avatar Workbench からランチャーを開きます。
  2. 共通 Avatar Root に編集対象のAvatarを指定します。自動検出または候補から選択できます。
  3. 目的に応じて PhysBone / Mask / Animation / Material / Preset Library の各Editorを開きます。
  4. Avatar Rootは各Editor間で共有されるため、同じAvatarを基準に作業を切り替えられます。
